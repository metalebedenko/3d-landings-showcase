# Security and demo boundaries

This repository is a standalone static portfolio snapshot. It does not include production deployment, server configuration, credentials, private development history, or commercial proposals.

The pages use local scripts, fonts and images. Lead forms produce an on-page preview only: no Telegram navigation, clipboard write, form endpoint, analytics, cookies, or persistent storage are required. The calculator reads a selected local file in browser memory; no upload endpoint is provided.

If you host the demo, your hosting provider can still receive ordinary HTTP request information such as IP addresses. This repository does not make a privacy guarantee for third-party hosting or browser extensions.

Use synthetic form values and synthetic, non-confidential STL files. The calculator is an approximate demonstration, not a validated manufacturing or pricing service. Large or malformed files are rejected; the parser is not a general-purpose CAD validator.

For bugs, open an issue with a minimal synthetic reproduction. Do not include credentials, private models, real requests, customer information, or details of retired infrastructure. There is no guaranteed maintenance schedule. Review the code and third-party asset terms before adapting it for a live service.
